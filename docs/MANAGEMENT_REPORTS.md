## Implementation rules

Canonical source queries reuse installment/receivable/expense/payroll balance views. `report_cash_rows` uses signed actual treasury legs and immutable receipt lines; receipt reversals are effective-date legs, not deletion of original income. Shared receipts split by child line for classroom totals. Actual payroll advances and final positive settlements are cash outflows; basic salary, deductions, pending expenses, debt and debt ownership transfers are not cash. Cash result excludes internal transfers/opening/closing adjustments. Additional-fee income has a separate report without counting it twice. Unattributed operating costs have a branch-only report; classroom cash contribution never allocates branch rent artificially. Account balances are as of end date; child/capacity/current debt views are explicitly labelled current snapshots. No grade averages across incompatible grading formats.

Reports use one aggregate and one bounded page query (limit100, offset100000). Exports read every filtered row up to10000, explicitly fail above cap, never silently truncate. Private files are64MB bounded and hash verified in the existing path/symlink-defended private store namespace, never public web files. Creator+operation UUID is unique, identical replay returns the same request, changed replay conflicts. Expiry24hours from request. Current creator capabilities, account/license and original branch/classroom scope are revalidated in the worker and download; expanding scope does not widen saved requests. Download remains creator-only, including against System users. Operational child reports also intersect current child placement with original record authority; historical financial receipt attribution retains Phase17 branch/classroom snapshots. Current operational child download checks use one UUID-array query, eliminating the earlier per-child SQL N+1.

pg-boss `management-report-exports-v1` persists Cairo minute/startup sweeps. One report per sweep, three persisted attempts with30s delay; transient failures roll back READY state, remove unreferenced newly written files, and retry. Permission/row-cap failures terminate explicitly. Row locks and idempotency prevent duplicate generation/financial effects. Expired metadata/files are cleaned20 per sweep even with pending work. Renderer uses existing bundled OFL Noto Sans Arabic/Pango300dpi raster PDF approach (not searchable), A4 pagination and branding.
